# Hoja de vida - Heidy Francheska Figueroa Zamora

Sitio estatico (HTML/CSS/JS + Bootstrap) que muestra la hoja de vida y portafolio.

## Estructura
- index.html - pagina principal
- img/ - imagenes del portafolio

## Despliegue en Render
1. Sube este repositorio a GitHub.
2. En Render, crea un **Static Site**.
3. Conecta el repositorio de GitHub.
4. Publish directory: / (raiz). Build command: (vacio).
5. Render servira index.html automaticamente.
